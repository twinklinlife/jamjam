# Ragdoll Archer Quest

드래그로 조준해 화살을 쏘고, 부위 명중으로 적을 쓰러뜨리며 10개 스테이지를 돌파하는
싱글 플레이 라그돌 아처 게임. Phaser 3 + Matter physics로 구현된 단일 `index.html` 파일.

- **폴더**: `jamjam/ragdoll-archer-quest`
- **최종 제출 파일**: `jamjam/ragdoll-archer-quest/index.html`
- **기술 스택**: Phaser 3 (CDN) + 내장 Matter physics, 외부 이미지 asset 없음(전부 도형), localStorage 저장

## 조작 방법

- **드래그 조준 → 놓아서 발사**: 화면 아무 곳이나 눌러서 당기면 조준 궤적(점선)이 표시되고,
  놓으면 그 방향/힘으로 화살이 발사됩니다.
- 마우스와 터치 모두 동일하게 동작하며, 키보드는 사용하지 않습니다(iframe 포커스 문제 방지).
- 짧게 당겼다 놓으면 발사가 취소됩니다.

## 게임 루프

1. 스테이지 시작 → 적 아처와 대결 (부위별 명중 = 데미지 = 점수: 머리 40 / 몸통 20 / 팔다리 10)
2. 적 처치 → 골드 획득 → 상점(스탯/장비 구매) → 다음 스테이지
3. 5, 10 스테이지는 보스(HP·보상 대폭 증가)
4. 사망 또는 10스테이지 클리어 시 결과 화면 + 로컬 리더보드 갱신

진행 상황(스테이지, 골드, 보유/장착 장비, 최고 기록, 리더보드)은 `localStorage`에 저장되어
새로고침 후에도 "이어하기"로 계속할 수 있습니다.

## 로컬에서 테스트하기

별도 빌드 과정이 필요 없는 순수 정적 HTML입니다. 아래 중 편한 방법으로 로컬 서버를 띄워 확인하세요.

```bash
# Node.js가 있다면
npx serve ragdoll-archer-quest

# 또는 Python 3
cd ragdoll-archer-quest
python -m http.server 8080
```

브라우저에서 표시된 주소로 접속해 플레이합니다. `index.html`을 파일로 직접 더블클릭해서 열어도
대부분의 브라우저에서 정상 동작하지만, 로컬 서버로 여는 것을 권장합니다.

콘솔에 에러가 없는지(F12 개발자 도구 → Console) 확인하세요.

## PagePort 업로드 및 iframe 테스트

1. [PagePort](https://pageport.anipangfriends.com)에 `ragdoll-archer-quest/index.html` 파일을 업로드합니다.
2. 발급된 URL을 브라우저에서 직접 열어 전체 플레이(조준 → 발사 → 스테이지 클리어 → 상점 →
   사망/승리 → 리더보드)가 정상 동작하는지 확인합니다.
3. 제출 페이지에 URL을 입력한 뒤, **iframe 안에서** 아래 항목이 정상 동작하는지 반드시 확인합니다.
   - 드래그 조준 및 발사 (마우스/터치)
   - 상점 구매/장착 버튼 클릭
   - 메뉴·결과 화면의 리더보드 노출
   - 새 창/팝업/다운로드가 발생하지 않는지

## 문제 발생 시 체크 목록

- 화면에 스크롤바가 보인다 → 브라우저 확대/축소를 100%로 되돌리고 새로고침
- iframe 안에서 드래그가 안 먹힌다 → iframe에 포커스가 필요한 것이 아니라 pointer 이벤트만
  사용하므로, iframe 자체가 정상적으로 렌더링되는지(예: `allow`/`sandbox` 속성이 pointer 이벤트를
  막고 있지 않은지) 확인
- 리더보드/진행 상황이 초기화된다 → 브라우저의 localStorage가 차단되어 있거나(시크릿 모드 등)
  다른 도메인/포트로 접속했을 가능성이 있습니다(도메인·포트가 바뀌면 localStorage도 별도로 취급됩니다)
- 온라인 리더보드는 포함되어 있지 않습니다(로컬 리더보드만 사용). 필요 시 Supabase 등을 추가로
  연동할 수 있으나, 연동 실패 시에도 게임과 로컬 리더보드는 항상 정상 동작해야 합니다.
